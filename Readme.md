# 🏦 My Bank — Banking Application

A simple banking application built using Java OOP concepts, HTML, CSS, and JavaScript. This project demonstrates basic banking operations through a user-friendly interface.

🔗 Live Demo

Click here to view My Bank Website

View Source Code on GitHub

## ✨ Features

- PIN-based demo login
- Check account balance
- Deposit money
- Withdraw money
- View account details
- Mini transaction statement
- Responsive passbook-inspired interface

## 🛠️ Technologies Used

- Java — Object-Oriented Programming
- HTML5 — Webpage structure
- CSS3 — Styling and layout
- JavaScript — Banking operations and interactivity
- Git & GitHub — Version control

## 🔐 Demo Login

- Demo PIN: `2580`
- Initial balance: ₹1,000

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `src/com/bank/index.html` in your browser.
4. Enter the demo PIN to explore the application.

## 📚 Concepts Practiced

- Classes and objects
- Constructors and methods
- Encapsulation concepts
- Conditional statements
- DOM manipulation
- Event listeners
- Basic input validation

## ⚠️ Disclaimer

This project is created for educational purposes only. It is a frontend banking simulation and does not use a real bank account, database, or secure authentication system.
